# MridaCraft Backend

Express + MongoDB API for the MridaCraft (Lippan art) e-commerce store.
Authentication is **Google Sign-In only** — there is no email/password login.

See the main project README (shared with the frontend zip) for full setup and
Render deployment steps.

Quick start:

```bash
npm install
cp .env.example .env   # then fill in the values
npm run seed            # optional: adds 4 demo products
npm run dev              # http://localhost:3000
```
